# Rann Voyages / Prateek Holidayz Website Handover Summary

## Project Overview

This project is a premium travel agency website for **Prateek Holidayz**, also named **Rann Voyages** at the repo level. It is built with **Next.js App Router**, **React**, **TypeScript**, **Tailwind CSS v4**, **Framer Motion**, and **Phosphor Icons**.

The current website is a polished static-first brochure and lead-generation site. It presents leisure travel packages, pilgrimage/yatra packages, international trips, and corporate/MICE travel services. It also includes contact and inquiry forms that submit to a backend API route, which then forwards inquiries to a configured webhook.

## Current Tech Stack

- Next.js `16.2.10`
- React `19.2.4`
- TypeScript with `strict: true`
- Tailwind CSS v4 via CSS `@theme inline`
- Framer Motion for reveal, hero, stagger, and menu animations
- Phosphor Icons for UI icons
- `next/font/google` for Fraunces and Manrope
- `next/image` for optimized remote imagery

## Current Architecture

The app uses the `src` directory:

- `src/app` contains routes, metadata, global CSS, generated SEO files, and the API route.
- `src/components` contains reusable UI components.
- `src/lib/data.ts` contains all package, corporate service, testimonial, navigation, and company data.
- `src/lib/fonts.ts` configures Google fonts.

The site is mostly static. Package data is imported directly from `src/lib/data.ts`, so there is no database, CMS, authentication, admin panel, or external content API yet.

## Performance Status

The site is relatively efficient because most pages are Server Components and data is static. It uses `next/image`, static route generation for package pages, and no heavy database/API waterfalls.

Performance risks:

- Several visual components are client components because of Framer Motion.
- `PackageCard` is client-side only mainly for hover animation.
- All main visuals are remote Unsplash images.
- There are no blur placeholders.
- `PageHero` always marks images as `priority`.
- Build depends on Google Fonts access unless fonts are self-hosted.

Recommended performance improvements:

- Make `PackageCard` server-first or reduce its animation cost.
- Add a `priority` prop to `PageHero` instead of always enabling it.
- Add blur placeholders or local curated image assets.
- Consider self-hosting fonts and key brand imagery.
- Add Lighthouse budgets before production.

## Security Status

The main production concern is `/api/inquiry`.

Current behavior:

- Accepts JSON POST requests.
- Validates required fields.
- Requires name, email, phone.
- Requires company for corporate inquiries.
- Forwards valid inquiries to `INQUIRY_WEBHOOK_URL`.
- Returns clear user-facing errors if the webhook is unavailable.

Missing production protections:

- Rate limiting
- CAPTCHA or bot protection
- Strong schema validation
- Phone validation
- Payload size limits
- Webhook timeout handling
- Request logging/monitoring
- Abuse protection

Dependency audit also found vulnerabilities through current Next.js dependencies:

- PostCSS advisory
- Sharp/libvips advisory

Do not blindly run `npm audit fix --force`, because npm suggested a breaking change path.

## Overall Assessment

This is a strong premium travel website MVP. It is visually polished, cleanly organized, and already has good static SEO foundations. The codebase is small, readable, and TypeScript/lint clean.

The biggest gap is that it is still a brochure and lead-generation site rather than a complete booking platform. The next agent should focus first on production hardening, inquiry reliability, security, conversion UX, and package-specific lead capture before adding large new features.
